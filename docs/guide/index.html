Get started in a minute

PackWise looks like a classic archive manager: a toolbar on top, an address bar, the file list and a details pane on the right.

  1. Find your files. Browse folders in the list just like File Explorer. Double-click to go into a folder; press Backspace to go up.
  2. Open an archive. Double-click any ZIP, 7Z, RAR or other archive. You can now browse inside it like a folder.
  3. Use the toolbar. Add packs files, Extract To unpacks, Test checks for damage, View opens a file, Delete removes it.
  4. Look at the details pane. Select something to see its size, type and a preview of images and text — even inside archives.

The first time you start PackWise a short tour explains the basics. Open it again with Help › Getting started or F1.

Open and browse archives

  • Double-click an archive, drag it onto the window, or use File › Open archive (Ctrl+O).
  • Click any part of the address bar to jump there, or click its empty space to type a path.
  • Type in Filter by name (Ctrl+F) to narrow the list. Turn on Whole archive to search every folder inside.
  • Archives inside archives open too — double-click them.
  • Encrypted archives ask for the password once; PackWise remembers it until you close the app.

The status bar shows the archive format and badges such as Encrypted, From the internet or Damaged.

Extract files

  1. Open the archive. Select specific files, or select nothing to extract everything.
  2. Click Extract To (Alt+E).
  3. Check the destination. PackWise suggests a new folder named after the archive and shows the free space.
  4. Choose what happens if a file already exists: Ask me, Keep both, Skip or Replace.
  5. Read any notices (for example, programs inside the archive), then click Extract.

Quicker options

  • Extract here unpacks next to the archive, creating a folder only when the archive has many loose files.
  • Extract to its own folder always creates a folder named after the archive.

If a file inside an archive tries to land outside the destination — a known trick in malicious archives — PackWise blocks it and tells you.

Create an archive

  1. Browse to your files, select the files and folders you want, and click Add (Alt+A).
  2. Choose a format: ZIP opens almost anywhere; 7Z is usually smaller.
  3. Pick a compression level. Balanced is right for most things; photos and videos barely shrink, so Store is fastest for them.
  4. Optional: tick Protect with a password for AES-256 encryption. With 7Z you can also hide the file names.
  5. Click Create. PackWise tests the new archive automatically.

Nobody, including PackWise, can recover a lost password. Use Generate strong password and store it somewhere safe. Windows File Explorer cannot open encrypted ZIP files; recipients need PackWise, 7-Zip or similar.

To add files to an archive you already have, open it and click Add, or drag files onto the window.

Right-click menu in File Explorer

Do common jobs without opening PackWise.

  1. In File Explorer, select one or more files or folders and right-click.
  2. On Windows 11, choose Show more options (or press Shift+F10). On Windows 10 the menu appears straight away.
  3. Point to PackWise and choose a command.

Convert and test archives

  • Commands › Convert to ZIP / 7Z re-packs an archive. PackWise unpacks it privately, compresses it again, tests the result and keeps the original. Passwords carry over.
  • Test (Alt+T) verifies every file. If something is damaged, the report names the exact files. PackWise does not repair archives; download the file again or extract what is intact.
  • Info (Alt+I) shows the format, compression, encryption, origin and what PackWise can do with that format.

Find duplicate files

  1. Click Duplicates on the toolbar. The current folder is added automatically; use Add folder… for more.
  2. Click Scan for duplicates. PackWise compares file contents, never just names.
  3. Review the groups. Use Select all but: Newest / Oldest / Shortest path / In first folder to tick copies quickly.
  4. Click Move to Recycle Bin, or Move to review folder… to set them aside.
  • PackWise always keeps at least one copy of every group.
  • Online-only OneDrive files are skipped so nothing is downloaded behind your back.
  • Identical copies can be intentional backups — check before removing.

Checksums

Select files and click Checksums to compute CRC32, SHA-256 and SHA-512. Paste a value published by a website into Compare with to confirm your download matches. Save checksum file writes a standard .sha256 file; the Verify tab checks one.

How PackWise keeps you safe

Contained extractionFiles can't be written outside the folder you choose. Links and hidden data streams in archives are never created.
No silent overwritesYou decide every conflict. Replaced files go to the Recycle Bin.
Internet mark keptFiles from downloaded archives keep Windows' Mark-of-the-Web, so SmartScreen and Office still warn you.
Honest warningsPrograms, scripts, macro documents and disguised names like invoice.pdf.exe are flagged. This is a hint, not a virus scan.
Fewer risky formatsRarely needed formats such as disk images and installers stay closed unless you enable them in Settings › Formats.
PrivateNo account, no ads, no telemetry. Nothing is uploaded, ever.

Questions

Can PackWise create RAR files?

No. RAR creation is proprietary. PackWise opens and extracts RAR, and creates ZIP and 7Z.

Why is the right-click menu under "Show more options" on Windows 11?

Windows 11's compact menu only accepts apps with a signed package identity. PackWise uses the classic menu, which works everywhere and needs no administrator rights.

How do I make PackWise open .zip files by default?

Turn on Offer PackWise for archive files in Settings › Windows, then open Default apps and choose PackWise for the file types you want. Windows only lets you, not apps, change defaults.

How do I uninstall?

Open Windows Settings › Apps › Installed apps, find PackWise and choose Uninstall. Your files and archives are not touched.

Where are settings and logs stored?

In %LOCALAPPDATA%\Northstar Labs\PackWise. Logs record operations and paths only — never passwords or file contents — and can be turned off in Settings › Privacy.
