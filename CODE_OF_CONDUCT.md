# Code of conduct

PackWise follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the work, and help make the
project welcoming to people of every background and experience level.

Report unacceptable behaviour privately to the maintainers through
[GitHub security advisories](https://github.com/whynotdhyan/PackWise/security/advisories/new)
or by contacting Northstar Labs. Reports are handled confidentially.
